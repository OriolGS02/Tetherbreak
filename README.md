# Tetherbreak



&#x09;Tetherbreak is a personal Unity game development project focused on building a top-down sci-fi action game.



&#x09;The project is currently in its early prototyping stage. Development is ongoing, with an initial focus on player movement and orientation.





#### Project Status:



&#x09;In Development — Early Prototype





#### Current Features:



&#x09;Player movement.



&#x09;Player orientation.





#### Development Goals:



&#x09;The project will be developed incrementally, with a focus on gameplay programming, modular systems, and maintainable C# code.



&#x09;Further features and technical details will be documented as they are implemented.





#### Technologies:



&#x09;Game Engine: Unity



&#x09;Programming Language: C#





#### Project Structure:



&#x09;The repository contains the Unity project files, including game assets, package configuration, and project settings.





#### About This Project:



&#x09;Tetherbreak is a personal project created to practise and demonstrate game programming skills through hands-on development.



&#x09;This repository will evolve alongside the project, documenting its implementation and technical decisions as development progresses.
